⚔ フェリスのプロフィール＆チャットルーム ⚔

HTML・CSS・JavaScript の基礎学習（Unit 5〜7 のまとめ）として制作した、オリジナルの自己紹介サイトおよび簡易チャットWebアプリケーションです。

🌟 主な機能

自己紹介ページ (index.html)

基本情報、好きなこと・特技、ひとことメッセージをカード型の「箱デザイン」でわかりやすく表示します。

ページ内スクロールナビゲーションおよびチャット画面への遷移ボタンを備えています。

チャットルーム (chat.html)

JavaScript（DOM操作・イベント処理）を使用し、メッセージの送信と吹き出しの動的追加に対応しています。

入力されたキーワード（「年齢」「出身」「趣味」「寝不足」など）に応じて、フェリスらしい返信を自動で返します。

📁 ディレクトリ構成

profile/
├── index.html          # 自己紹介ページ（トップページ）
├── chat.html           # チャットルーム画面
├── script.js           # チャットの送受信・自動返信ロジック
├── README.md           # プロジェクト説明書
└── css/
    ├── style.css       # 自己紹介ページ用スタイルシート
    └── chat.css        # チャットルーム用スタイルシート


🚀 使い方・起動方法

特別なサーバー環境やインストール作業は不要です。

profile/ フォルダ内の index.html をダブルクリックするか、ブラウザ（Chrome, Edge, Safari など）にドラッグ＆ドロップして開きます。

画面上部の「💬 チャットで話す」ボタンをクリックすると、chat.html に移動します。

チャット画面下部の入力欄にメッセージを入力して「送信」ボタンを押すと会話が始まります。

🛠️ 使用技術

HTML5（セマンティックな構造化、フォーム要素）

CSS3（Flexboxレイアウト、ボックスデザイン、アニメーション）

JavaScript (ES6+)（DOM操作、イベントリスナー、条件分岐による簡易応答）
